# 6DOF_mixer
A temporary repo to house my research on fully articulated aircraft control  

There are two stages to this project: \
1). converting the global commands to the aircraft local coordinate frame. (vis.py and quaternion.py) \
2). converting local coordinate commands to individual actuator outputs. (Kinematics_test.py and mixing_matrix_generator.py) 

Current state: The project is working as intended, however, much more testing and refinements are needed. 

The lastest code can be found under the "releases" tab.
